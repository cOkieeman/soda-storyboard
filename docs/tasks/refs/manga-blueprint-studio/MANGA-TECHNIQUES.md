# 漫画演出ガイド — Manga Direction Techniques

このガイドは用語暗記ではなく、**読者に何を感じさせたいか**から漫画技法を選ぶためのものです。Manga Blueprint Studioでは技法そのものより、技法が担う意図を正本として扱います。

## まず覚える原則

漫画のページは静止画の集合ではありません。読者の目を「どこから入り、何を見て、どこへ抜け、次に何を見るか」まで設計する時間表現です。

- **重要度**: 物語上・絵として・つなぎとして、どのコマを強くするか。
- **間**: 読者をどれだけその瞬間に滞在させるか。
- **視線誘導**: 顔、視線、動き、吹き出し、コマ形状で次の注目点へ導く。
- **読み順**: 日本漫画の標準は右上から左下へ。文字方向とは別の概念。
- **コントラスト**: 大小、静動、遠近、密疎の差が演出を作る。全部を強くすると全部が弱くなる。

## 大ゴマ / Hero panel

ページ内で相対的に大きな面積を与えるコマです。決め絵、感情のピーク、場所の提示など、読者を長く滞在させたい場面に向きます。

**向く場面:** クライマックス、初登場、必殺技、重要な表情、広い舞台の提示。

**注意:** 「重要だから必ず大ゴマ」ではありません。前後との差が重要です。短い衝撃なら小さく鋭いコマの方が効く場合もあります。

## 小ゴマ / Beat panel

短い時間、反応、細部、つなぎを刻みます。連続させるとテンポを上げやすく、細かな変化を見せられます。

**向く場面:** 視線だけ動く、手が止まる、通知を見る、一瞬のリアクション。

## 斜めコマ

枠線を傾け、ページに方向性と不安定さを作ります。アクションの進行方向と揃えると運動感を補強できます。

**向く場面:** 衝突、転倒、急加速、緊張、不安定な心理。

**注意:** 全コマを斜めにすると基準がなくなり効果が弱まります。静かな矩形との対比が有効です。

斜め枠の隣に四角いコマがあると、コマ間が三角形に大きく空く場合があります。Name DSLで `境界連動: paired` を明示すると、同段の未固定・未変形コマとの間に一定の余白を保つよう、相手側の辺も平行に合わせます。既定の `independent` は隣を変形しません。相手が固定済み・別段・既に斜め等の場合は診断だけを記録します。断ち切り・余白ゼロ・上下位置調整は別の演出であり自動的には適用しません。

## 断ち切り / Bleed

絵をページの仕上がり端まで到達させ、通常の余白・枠による閉じ込めを弱める演出です。画面の外にも世界が続く感覚やスケールを出せます。

**向く場面:** 景色、登場、強いアクション、ページを支配する瞬間。

**制作上:** 印刷では仕上がり線より外側まで絵が必要です。重要な顔や文字を裁ち落とし付近へ置かない設計が必要です。

## ブチ抜き / Character breakout

人物や物体を通常のコマ枠の内側だけに閉じず、枠を越えて見せる演出です。存在感や勢いを強め、複数領域を視覚的につなげられます。

**向く場面:** 主役の登場、必殺技、大きな動作、強い感情。

**AIへの伝達:** 「人物が大きい」だけでなく、**どの枠を越え、どこまでが前景として重なるか**を空間契約として持つ必要があります。

## 小窓 / Inset panel

大きな親コマの上に小さなコマを重ね、同時刻の細部や反応を追加します。

**向く場面:** 目のアップ、手元、モニター、別人物の反応、同じ瞬間の補足。

**注意:** 小窓が親コマの重要部分を隠さないこと。読み順が曖昧にならない位置に置きます。

## 視線誘導

キャラクターの目線は強い矢印です。人物Aが左下を見ると、読者も左下を探しやすくなります。顔の向き、腕、武器、速度線、吹き出しの尾も同じ役割を持ちます。

```text
右上の顔
   ↙ gaze
中央の手
   ↙ motion
左下の結果
   ↓
次のコマ
```

**基本:** 読み順と逆向きの強い視線・動線を置く場合は、意図的な「引っ掛かり」なのか確認します。

## 動線 / Motion flow

走る、殴る、落ちる、振り向くなどの動きには方向があります。コマ内の動きの出口を次コマの入口へ近づけると、ページを滑らかに読ませられます。

アクションでは「動作前 → 接触 → 結果」を全部同じ強さで描かず、どの瞬間を見せるか選びます。

## カメラ距離

- **Long / Wide**: 場所、距離、全身関係を理解させる。
- **Medium**: 人物の動作と表情を両立。
- **Close-up**: 感情、情報、重要な部位へ集中。
- **Extreme close-up**: 目、指、傷、物など一点を強調。

同じ距離を続けるより、遠景→中景→アップの変化で情報量と感情の波を作れます。

## アングル

- **Low angle / あおり**: 大きさ、圧、優位性、迫力。
- **High angle / 俯瞰**: 状況把握、小ささ、距離感。
- **Dutch angle / 傾き**: 不安定、衝撃、異常。
- **Eye level**: 基準となる自然な会話・日常。

アングルは感情のラベルではなく、画面内の空間関係を変える道具です。

## 「間」

セリフも大事件もないコマが、時間を作ることがあります。空の椅子、止まった手、沈黙する顔、風景などを置くことで、次の情報を強くできます。

Manga Blueprint Studioでは重要度とは別に `hold` として考えます。重要だが一瞬で読ませたいコマと、情報は少ないが長く止めたいコマを区別するためです。

## ページめくり

紙・見開き漫画では、ページをめくるまで次の情報が見えないこと自体が演出になります。答え、怪物、告白、景色などを次ページ冒頭へ置けば reveal を制御できます。

Web/縦スクロールでは同じ物理的効果にならないため、媒体に応じて再設計します。

## 見開き

左右2ページを一つの大画面として使う表現です。圧倒的な景色やクライマックスに有効ですが、中央の綴じ部分へ顔や文字など重要情報を置かない配慮が必要です。

## 吹き出しも視線誘導

吹き出しは文字箱ではなく、読者の視線が必ず立ち寄る図形です。日本漫画なら右上→左下の読みを壊さない順番と位置を意識します。人物の顔を覆わないだけでなく、吹き出しから次の注目点へ自然につながる配置が有効です。

## SFX / 効果線

大きな擬音、集中線、速度線は「装飾」ではなく視線と力の方向を作ります。接触点へ集中線を集める、移動方向へ速度線を伸ばすなど、物理的な出来事と一致させると読みやすくなります。

## AIと共同制作するとき

AIへ「斜めコマにして」と技法名だけを渡すより、意図を一緒に保持します。

```yaml
beat:
  purpose: impact
  importance: high
  hold: low
  focus: swords.contact
  motion: down-left
```

そこからSolverが斜めコマ、大ゴマ、通常コマなど複数候補を比較できる方が、人間の演出意図を保ちやすくなります。

**技法は目的ではなく手段。** 人間は「何を読者に見せたいか」を決め、AI/Solverはそれを満たす構図候補を作り、人間が最終判断する、という分担を推奨します。
