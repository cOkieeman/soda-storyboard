# 任务书 P4b：分镜编辑器前端（交给 Gemini）

## 你要做什么

在 `E:\个人开发项目\soda-storyboard\editor\` 里做一个本地网页编辑器，用来查看和修改漫画分镜、选择版式、看草稿图、出图并挑选结果。

- **起点**：fork 开源项目 OpenKoma（React + TypeScript + Konva + Zustand，Apache-2.0）。本机已有一份副本：`E:\claude\OpenKoma`（提交 `aa8dbf3`），也可以从 `https://github.com/Reuben-Sun/OpenKoma` 获取同一版本。
- **后端已经写好**：本地服务 `soda-storyboard-serve`，接口文档在 `editor/API.md`（3000 多行，含请求和响应示例、错误码、ETag、SSE 事件、任务队列）。**前端只通过这些接口读写数据，不要直接读写项目文件，也不要改后端。**
- 使用者是一个没有漫画基础的中文用户，画日漫（从右往左读），平时在 Codex / Claude 里和 AI 讨论分镜，AI 会直接改项目文件；编辑器要和 AI 同时操作同一个项目而不互相覆盖。

## 背景

- 分镜单的核心数据（详见 `editor/API.md` 的字段说明）：
  - 页面：画布宽高、阅读方向、格子列表、文字列表（texts）、跨格人物（overlays）、画风段落（style_prompt）。
  - 格子：形状（矩形 `rect` 或四边形 `quad`，左上角原点像素）、阅读顺序、景别、角度、出场角色、火柴人（figures：谁、姿势、位置、朝向、景框）、英文描述（caption_en）、中文描述。
  - 文字：类型（台词 / 旁白 / 拟声 / 标题）、原文（可含换行）、所属格子、说话人、竖排或横排、气泡样式、位置框。
- 后端提供的草稿图（`GET /api/pages/{id}/preview.png?style=sketch`）已经画好了火柴人和文字框，配色是：格子青色、跨格人物红色、文字框绿色。
- OpenKoma 原有的能力要保留：格子拖动、四角拖成斜切、边中点推动、二次切割、透明图片图层、非破坏裁剪、文字气泡（横排 / 竖排）、多页、撤销重做、导出 PNG / PDF。第一版不一定都接上后端，但不要删掉。

## 第一版的范围（用户已确定）

**做：**
1. **左栏**：页面列表（缩略图用草稿图），角色列表（名字、LoRA 名、强度，只读即可）。
2. **中间画布**：
   - 显示当前页的格子（矩形和斜切）、文字框、跨格人物框，从右往左的阅读顺序编号。
   - 可以拖动和缩放格子、拖四角做斜切、拖动和缩放文字框。
   - 图层开关：草稿图（后端的 sketch 图，半透明叠在画布下）、当前选定的出图结果（作为底图，透明度可调）。
3. **右栏属性面板**（选中格子时）：景别、角度、出场角色（多选）、火柴人列表（姿势下拉、位置、朝向、景框）、英文描述、中文描述；选中文字框时：类型、原文（多行）、说话人、竖排 / 横排、气泡样式。
4. **顶部操作**：版式候选（调用 layout-suggest，弹出候选缩略图网格，点选后 layout-apply）、草稿预览（大图查看后端 sketch 图）、导出 JSON（调用 compile，显示保存路径并可复制 JSON）、出图（调用 generate，可选张数和草稿 / 定稿预设）。
5. **底部出图候选条**：显示该页的出图结果（`/renders`），点一张即 pick 为当前底图；出图任务进行中显示排队 / 进度 / 完成 / 失败（来自 `/api/jobs/{id}` 和 SSE）。
6. **保存**：编辑后自动保存（防抖，例如停止操作 1 秒后）或按 Ctrl+S；`PUT` 必须带 `If-Match`（ETag）。返回 409 时**不要覆盖**，弹出提示"页面已被外部修改"，提供"载入最新版本"和"查看差异后手动合并"（第一版可以只做载入最新版本，并保留本地未保存的修改供复制）。返回 422 时把问题列表显示在右栏，并在画布上标出出问题的格子。
7. **实时同步**：连接 `/api/events`（SSE）。收到当前页 `file_changed` 且本地没有未保存修改时自动刷新，并显示一条轻提示"页面已在外部修改"（事件带格子信息时写"AI 刚修改了第 N 格"）；有未保存修改时按 409 的方式提示。
8. **出图接口不可用时**（后端返回 501）：出图按钮显示为可点，点了提示"出图功能尚未安装"，不要隐藏或报错崩溃。

**这一版不做：** 角色库编辑页、版式库页、排字和导出 PDF 的后端接入、切格重画的界面（`plan` / `redraw` 接口先不接）。

## 界面风格：和 Soda Prompt Hub 一致

用户的另一个软件 Soda Prompt Hub 的样式文件已放在 `docs/tasks/refs/hub-style/`（`base.css` 是全局变量和组件，`creative.css` 是"创作台"页面）。照它来：

- **颜色变量**（直接复制这些 CSS 变量名和值）：`--ink #171815`、`--paper #ece8dc`、`--paper-deep #d8d1bf`、`--paper-lift #fbf6ec`、`--paper-surface #f4eddf`、`--paper-wash #e2dccd`、`--signal #9a321f`（砖红，主操作）、`--acid #d7e455`（荧光黄绿，点缀）、`--muted #5b5a53`、`--line rgba(23,24,21,.19)`、`--rule #bcb4a3`，以及 `--ink-lift`、`--ink-line`、`--signal-deep`、`--signal-wash`、`--scrim`、`--shadow`。
- **字体**：正文 `--font-sans`，大标题 `--font-serif`（宋体系），标签和按钮 `--font-mono`（等宽，小号、加粗、字距略宽）。字体栈照 `base.css` 复制。
- **组件**：直角（`border-radius: 0`）；按钮是 1px 黑框、透明底、等宽小字，悬停时向左上移 2px 并出现 `5px 5px 0` 的实心黑色投影；主按钮砖红底；次要按钮浅灰框。输入框 1px 浅线框、`--paper-lift` 底，聚焦时边框和底线变砖红。提示条左侧 4px 色条。
- **画布区域**：画布外的工作区用 `--paper-wash` 或 `--paper-deep`，漫画页本身是白纸（`#fff`）加细阴影，便于判断图片颜色。
- **去掉 OpenKoma 原来的深蓝色主题**和它的明暗切换，第一版只做 Hub 这一套浅色风格。
- 所有界面文字用中文。

## 技术要求

- 代码放在 `editor/`：保留 OpenKoma 的 `LICENSE`（Apache-2.0），新增 `editor/NOTICE` 写明 fork 自 OpenKoma、提交号和主要改动。
- 开发：Vite 开发服务器 `http://localhost:5173`，把 `/api` 代理到 `http://127.0.0.1:8780`（后端只允许这个开发来源跨域）。
- 构建：`npm run build` 输出到 `editor/dist`，后端用 `soda-storyboard-serve <项目目录> --static editor/dist` 直接托管。后端没有前端路由回退，用 HashRouter 或不用路由。
- 前端内部可以继续用 OpenKoma 的数据结构，但**以接口返回的分镜单为准**：读取时转换成画布对象，保存时转换回去，**未编辑的字段原样保留**（接口文档要求以完整对象读改写）。
  - 格子形状对应：OpenKoma 的格子位置加四角偏移 ↔ 分镜单的 `rect`（x, y, w, h）或 `quad`（四个角点）。四角都没有偏移时存成 `rect`。
- 不要引入新的 UI 框架；样式用 CSS 变量加普通 CSS（可沿用 OpenKoma 的 Tailwind，但颜色必须来自上面的变量）。
- `npm run build` 和 TypeScript 类型检查必须通过；保留并能运行 OpenKoma 原有的测试（如有）。

## 怎么在本机跑起来

1. 准备一个测试用项目（**不要直接改 `examples/` 里的文件**）：把 `E:\个人开发项目\soda-storyboard\examples\pudding` 复制到一个临时目录。
2. 启动后端：在 `E:\个人开发项目\soda-storyboard` 下运行 `uv run soda-storyboard-serve <临时目录> --port 8780`。
3. 启动前端：在 `editor/` 下 `npm install`、`npm run dev`，浏览器打开 `http://localhost:5173`。
4. 出图需要本机 ComfyUI 在 `127.0.0.1:8190`；**测试时不要点出图**，除非用户在场同意（会占用显卡）。可以用后端返回 501 或任务失败的情况测试界面。
