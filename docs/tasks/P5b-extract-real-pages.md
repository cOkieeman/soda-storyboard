# 派单 P5b：让"从参考页提取版式"在真实漫画页上可用

前置：P5 已提交（`6aeb397`）。

目标：
P5 的 `layout extract` 在程序生成的测试页上全部正确，但在真实的漫画页上几乎失效。修改识别算法，让下面 5 张真实页面的格子能识别对。

背景与必要事实：
- Claude 验收时的实测结果（`uv run soda-storyboard layout extract <图片> --preview ...`）：

| 样本（`docs/tasks/refs/extract-samples/`） | 实际格数 | P5 识别结果 |
|---|---|---|
| `s1_pudding_color.png`：彩色，白色留白加黑色细格框，6 个格（上排 2、中排左右 2 个小竖格加中间 1 个格、下方 1 个宽格），中间有人物越过格框 | 6 | **0 个** |
| `s2_bw_manga_6.png`：黑白，左上 3 个小格纵向堆叠，右上 1 个高格，下排 2 个格；画面大量网点和细线 | 6 | 4 个（左上 3 格合成一个，置信度低） |
| `s3_misaki_5.png`：彩色，上排左宽格和右高格，中左格，下方大格内左下角还有一个嵌入的小竖格；有标题 logo 压在格框上 | 5（含嵌入小格） | 5 个，但多数位置不对、置信度低 |
| `s4_maid_light_frames_6.png`：彩色，**浅蓝色细格框**（不是黑色），3 行各 2 格，中间一个人物没有格框、压在中间几格上 | 6 | **0 个** |
| `s5_bw_4panel.png`：黑白 4 格（上方宽格、中间右左两格、下方宽格） | 4 | （请自测） |

- 这些样本放在 `docs/tasks/refs/extract-samples/`，已被 `.gitignore` 忽略（其中 s2～s4 不是本项目的作品，**不能提交进仓库、不能复制进 `examples/` 或测试目录**）。测试时直接从这个目录读取；目录不存在时相关测试跳过（`pytest.skip`），让公开仓库的 CI 仍能通过。
- 只能用 Pillow 和标准库（没有 numpy / OpenCV，也装不了）。可以把图缩到长边 800 左右再处理。
- 真实页面的难点：画面内容一直画到格框边上，格子之间的白色留白很窄；格框可能是黑色、灰色或浅彩色；人物、对话框、标题会越过格框；网点和背景线条会干扰投影。只靠"整行整列都是白色"的投影切分会失败。

执行目录（绝对路径）：E:\个人开发项目\soda-storyboard

可读取的范围：本仓库全部内容。

允许改动的文件/目录：`src/soda_storyboard/extract.py`（可拆成多个文件放进 `src/soda_storyboard/extract/` 包，保持对外函数和命令不变）、`tests/test_extract.py`（可新增 `tests/test_extract_real.py`）、`examples/layout-extract/`（只能放程序生成的样本）、`README.md` 中提取版式的章节。

禁止修改的文件/目录：`docs/`、`editor/`、其他模块。

其他约束：不得 push、部署、改系统设置、读取或输出密钥；不访问网络。

需要的操作：
1. **改进识别**（建议思路，可自行调整）：
   - 先找"格框"：检测长的直线段（横、竖，以及接近横竖的斜线），颜色不限于黑色（按与局部背景的对比度判断，浅蓝色细框也要能找到）；再找"留白"：窄的、贯穿的浅色带。两者结合确定分割线。
   - 允许分割线不贯穿整页（递归时只要求贯穿当前区域），并容忍分割线被人物、对话框、标题局部遮挡（例如一条分割线有 70% 以上长度可见就算）。
   - 对每个候选区域检查四边是否大致有格框或留白，用来给出置信度。
   - 支持"格中格"（s3 下方大格里嵌入的小格）：大格内部再找一个四边闭合的小矩形。
   - 越过格框、没有格框的人物（s1、s4 中间）不应被当成格子，也不应导致整页识别失败。
2. **阅读顺序**沿用 P5 的规则（日漫：先行后列、行内从右往左）。
3. **测试**：
   - 保留 P5 的生成样本测试，全部仍要通过。
   - 新增真实样本测试（样本目录不存在时跳过）：s1、s2、s4、s5 的格数必须完全正确，每个识别出的格子与人工标注的格子重叠度（IoU）≥ 0.8；s3 至少识别出 4 个主要格子（嵌入小格识别出来更好）。人工标注写在测试代码里（用相对坐标，你根据图片自己标，不要把图片复制出来）。
   - 在生成样本里补几种接近真实页面的情况：画面画满到格框边、窄留白（3～6 像素）、浅彩色格框、越过格框的人物和对话框、格中格。
4. 识别结果仍然输出置信度；某页实在识别不好时，结果里给出明确提示（例如"识别不可靠，建议手动调整"），不要静默输出错误结果。

完成标准：
- `uv run ruff format --check .`、`uv run ruff check .`、`uv run pytest` 全部通过（有样本目录时真实样本测试也要通过）。
- 对 5 个真实样本分别运行 `layout extract --preview`，叠加预览图里格子框基本落在真实格框上，阅读顺序正确。
- README 写清识别的适用范围和已知局限。

遇到阻塞：停止越界操作，在结果中说明，不自行扩大范围。

输出格式：结果摘要；改动清单（路径及原因）；每个真实样本的识别结果（格数、IoU、置信度）；验证命令与结果；已知局限。
