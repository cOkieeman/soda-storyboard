# 第 0 阶段：MOSS 整页布局快速验证

日期：2026-10-20。目的：开发前确认 MOSS 能否照分镜 JSON 画出整页漫画。
图像好坏由用户人工判断；本文只记录测试设置和每张图要看什么。

## 设置

- 直接调 ComfyUI API（`127.0.0.1:8190`），不经过 Soda-MOSS v2 界面，参数与 v2 的 25 步快速档一致：
  MOSS-Image SFT INT8、qwen3.5_9b_w4a8 编码器、flux2-vae、ModelSamplingAuraFlow shift 5、
  KSampler 25 步 / er_sde / simple / CFG 2.5、无 SLG、无二采、无超分。
- 画布 1024×1536，黑白日漫，从右往左读。
- 布局 JSON 用官方格式：bbox 为 `[y_min, x_min, y_max, x_max]`，中心原点，带 `bbox_coord_space` 和 `bbox_format`。
- 用到的 JSON 存在 `docs/research/phase0/`；测试脚本见 `docs/research/phase0/phase0.py`。
- 出图在 `F:\soda comfyui\ComfyUI_windows_portable\ComfyUI\output\MOSS\phase0\`。

## 用时（本机 16GB 显卡，模型已在显存）

- 整页 1024×1536，25 步：每张约 36～39 秒。
- 单格重画（1024 宽），25 步：每张约 24 秒。

## 结论（2026-10-20，用户看图）

1. **整页一次出图可行，作为主路。** 格子按 bbox 排，中文台词表现超出预期（T1）；单人物 LoRA 跨格一致（T2）。
2. **两个人物 LoRA 同时加载不可行。** 一个 LoRA 会把另一个角色完全吃掉（T3）。多人页要改流程：整页只加载一个角色的 LoRA（或不加），再对其他角色出场的格子单独重画，每次只加载那个角色的 LoRA。两人同格时，按人物位置做局部重绘，或者用两人合训的 LoRA。
3. **切格重画可行，降噪默认 0.45。** 0.65 会改动画面里的文字（中文变日文）。重画时要保护台词：要么把原格的气泡区域贴回去，要么在重画提示词里写明中文原文，要么该页改用程序排字。
4. 第 3 阶段按以上结论调整，见 `docs/PLAN.md`。
