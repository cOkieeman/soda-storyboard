# 看参考页补分镜内容

> 思路改写自 [wuhehen176/ComfyUI-MOSS-MangaLayout](https://github.com/wuhehen176/ComfyUI-MOSS-MangaLayout) 的参考图反推规则（`layout-rules.md`），经作者同意借用，按本工具的分镜单格式重写。

`layout extract` 只给出格子的几何和阅读顺序。这份说明用于下一步：由能看图的插件 AI 读参考页，把每格“画了什么”补进分镜单，用户就能“照这页的分镜，换成我的角色”。

## 分工

- **坐标以识别结果为准。** 格子的形状和顺序来自 `layout extract`，AI 不凭看图重画格子；觉得识别错了，先给用户看叠加图，请用户确认或调整。
- **AI 只填语义**：景别、机位、每格内容、人物站位和朝向、跨格人物、局部框。
- **原图台词不抄。** 只记录文字区的位置、用途（对白、旁白、拟声）和先后顺序，台词由用户的剧情提供。

## 逐格要写的内容

1. **景别和机位**：填 `shot`、`angle`，取值见 storyboard-format.md。
2. **description**：写这一格的叙事任务和看得见的内容：环境、光线、人物在做什么、视线朝哪。姿势写在这里，用文字描述。
3. **裁切位置**：照原图写清人物在哪里被格框截断，例如“头到大腿可见，下方被格框截断”。原图没画到的部分不要补成“全身”，否则人物会缩小、构图会变。
4. **表情**：依据看得见的线索写，例如眼睑、瞳孔、眉形、嘴形、头部朝向。看不出来的伤口、接触或攻防动作不要写。
5. **颜色**：黑白参考页只提供分格和构图。成图颜色跟用户的画风设定走，不要因为参考是黑白就写成网点黑白。

## 人物编号和替换

- 按整页首次出场的顺序，把人物叫作“角色1”“角色2”。同一个人跨格沿用同一个编号；位置或镜头变了，编号也不变。
- 判断是不是同一个人，看发型、头饰、服装、道具这些跨格重复出现的线索。判断不了就标“待确认”，只保留站位和轮廓，不要把猜测写成剧情。
- 用户确认“角色1 = 我的某某”后，写成 `figures` 的 `character_id`。外貌、服装以项目里的角色卡为准，不从原作角色身上继承。
- 人物的 `position`、`facing`、`framing` 照原图的站位、朝向和裁切填写。

## 同一个角色在一格里出现两次

原图把同一个人的放大脸部和较小的全身并排放在一格时，保留这种构图：在同一格写两个 `figures`，用同一个 `character_id`。编译器会自动注明“同一个人以不同尺度再次呈现，不是双胞胎，也不要拼成一个身体”。description 里也写清哪一个是脸部特写，哪一个是全身。

## 跨格和出框

- 人物明显跨过格线，或占了半页、从多格背景前方经过时，用 `overlays`（mode 选 moss）。`rect` 覆盖人物在整页实际占的范围。
- `description` 写清楚这次身体展示是连续的：从哪里延伸到哪里、越过哪几条格线、在哪些格子的背景前面，要避开哪些脸部和文字区。
- 只有发梢、手、鞋尖出框这种小范围，不必用 overlay，在所属格的 description 里写明，再配一个局部框就够了。

## 局部框：只在容易画错时加

抓握、屈膝、交叉的手脚、透视放大的手脚、出框的手，这类部位 MOSS 容易画错位置或画成悬空。这时给人物加一个 `objects` 局部框：

```json
{"id": "grab-hand", "panel_id": "p2", "owner": "<人物 id 或角色 id>", "part": "右手",
 "label": "character", "caption": "抓住角色2的袖口，手腕接着前臂", "rect": {"type": "rect", "x": 410, "y": 520, "w": 120, "h": 110}}
```

- `owner` 写这一格里那个人物的 id；旧页面没有人物 id 时写角色 id。
- `part` 写解剖学上的左右和部位。`caption` 写动作，以及它接着哪里、碰到什么、在什么前面或后面。
- 框要落在那个部位的实际位置，可以和人物框重叠。编译器会注明它属于同一个连续的身体，不会画成另一个人。
- 普通关节不用加。一格里加一两个局部框就够了，加多了反而互相打架。

## 交付前检查

- 格数、读序和 `layout extract` 结果一致，没有自己加格或删格。
- 每格都有景别、机位和 description，裁切位置照原图。
- 角色编号前后一致；“待确认”的地方已经问过用户。
- 跨格人物的 rect 和 description 对得上；局部框都有 owner 和 part。
- 没有抄原图台词，也没有写进原作角色的名字或作品专属标志。
