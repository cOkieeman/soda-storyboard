# 一页漫画怎么拆

这份笔记帮助把“发生了一件事”变成读者看得懂的先后顺序。经验是候选，不是必须遵守的公式；用户指定的节奏优先。知识整理来源见插件包 NOTICE。

## 一格只承担一个主要变化

先找“让读者知道什么”和“让读者感到什么”。四到六格常能容下一件小事；三格适合省略过程，七格适合细小反应。不要为凑格数重复同一信息。先把场景和人物位置交代清楚，再给眼神、手部或关键物件的近景。

## 景别就是看多近

| 字段值 | 给用户的解释 | 用途 |
| --- | --- | --- |
| extreme_long | 人很小，环境占大部分 | 先告诉读者在哪里、空间多大 |
| long | 整个人和周围环境一起看 | 交代谁站在哪、走向哪里 |
| full | 从头到脚看清动作 | 跑、停、转身等全身姿势 |
| medium | 像站近一点看半身 | 兼顾手势和表情，适合说话 |
| close_up | 镜头靠近脸或主要物件 | 让一个反应变得重要 |
| extreme_close_up | 只看眼睛、指尖等小部分 | 放大犹豫、线索或一瞬变化 |

别只说“换特写”，要说清“让读者看到她攥紧包带，知道她不想走”。

## 视线、运动和 180 度规则

默认右上开始，同段向左，再换下一段。人物看的方向、跑的方向和气泡位置会把读者带到下一格；不要让读者突然找不到人。阅读方向和文字横排/竖排是两件事。

两个人对坐时，想象他们之间有一条线。镜头尽量留在线的同一侧，让右边的人继续在右边、左边的人继续在左边，这就是常说的 180 度规则。需要换侧时，先用正面或环境格重新交代位置；别把规则当作不能突破的禁令。背面、过肩、朝左看写进 description，而不是新增 angle 枚举。

## 动作四拍

准备（交代起点）→ 预备（身体蓄力、手停一下）→ 动作（冲出、接触、转身）→ 反应（结果、旁人的表情）。不必每拍一格；省掉中间过程会更快，拆开细微变化会更慢。读者看不懂起点和结果时，再补中间一步。

## 对话与留一拍

说话的人 → 听者的反应 → 新信息 → 沉默或回答，是常用起点。别让每格都是同样大小的两张脸。可以让手、空座位、窗外的光承担停顿，但这些画面要和情绪有关。对白尽量短；本工具默认一句超过 20 字会警告，因为 MOSS 画长句容易错字。

## 大小与时间感

大格可能让读者停久一点，也可能只为展示场景；小格可能是很重要的一瞬。重要度不是“这格停多久”的同义词。连续小反应之后给大格，更容易留下落点；整页同样大小则更稳定。

## 收尾与翻页

一页就讲完时，可以停在一个动作、表情或没说完的话，不必强加下一页。连续页才考虑把答案藏在翻页之后；当前页末格先让读者产生问题。不要在同页上方提前露出原本想留到下一页的答案。
